Aco Recycling Thermal Printer Service

Connection

Plug the printer into your Ethernet port. The service scans every wired interface and lists Cashino-shaped listeners here — pick one and press Connect. In DEV_MODE the local mock device shows up so you can rehearse the flow without a cable.

    Pick from the dropdown above or type a path manually. Uses pyserial (USB-CDC), works for most Cashino USB printers.

    libusb fallback for vendor-class devices (no USB-CDC endpoint). Leave the path above empty to use this.

    Empty fields fall back to .env values. On mock backend the parameters are recorded but ignored (one simulated device serves both modes).
